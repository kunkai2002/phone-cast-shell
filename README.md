# phone-cast-shell

把手機投屏視窗包進一個 AI 對話介面的 Windows 小程式。手機畫面會出現在對話裡，看起來像使用者上傳的一張截圖，滑鼠照樣可以直接操作手機。

支援的投屏軟體：

| 軟體 | 狀態 |
|---|---|
| OPPO／一加 **O+互聯** | 實測過，裁切量已量好 |
| scrcpy | 內建「不裁切」（scrcpy 視窗本身就只有手機畫面），未實測 |
| escrcpy、QtScrcpy | 會自動找，裁切自動判斷，未實測 |
| Windows 手機連結（Phone Link） | 同上 |
| 華為／榮耀多屏協同、小米互聯、vivo 辦公套件、三星 | 同上，靠程式名稱關鍵字找，只認直式視窗 |
| AirDroid Cast、ApowerMirror、LetsView、Vysor、樂播投屏 | 同上 |
| 其他 | 設定 → 手動指定，之後會自動記住 |

未實測的軟體如果抓錯視窗或切錯邊，請到 Issues 回報程式名稱（工作管理員 → 詳細資料）和投屏視窗的截圖。

## 功能

- **嵌進對話**：投屏畫面變成對話裡的一張圖，標題列、工具列自動切掉，四角是圓的，捲動時跟著移動。
- **直接操作**：嵌進來的是投屏軟體本身的視窗，不是截圖，點擊、滑動的延遲跟原本一樣。
- **快速切換**：按 `Alt+Q`，手機畫面換成一張報表，整段對話也換成報表分析；再按一次換回來。哪個程式在前面都有效。
- **假的輸入框**：可以打字送出，會一個字一個字打出一段罐頭回覆。不連網，不需要任何金鑰。

## 下載與使用

1. 到 [Releases](../../releases) 下載 `PhoneCastShell-win-x64.zip`，解壓縮。
2. 需要 Windows 10／11、[.NET 8 桌面執行階段](https://dotnet.microsoft.com/download/dotnet/8.0)、WebView2 Runtime（Windows 11 內建）。
3. 先開始投屏，再打開 `PhoneCastShell.exe`，大約一秒內會自動接上投屏視窗。
   想從開始功能表打開：左下角頭像 → 設定 → 開始功能表，取個名字按「加到開始功能表」。程式會複製到 `%LOCALAPPDATA%\Programs\PhoneCastShell\`，之後解壓縮的資料夾可以刪掉。按「移除」會拿掉捷徑和那個資料夾。不寫登錄檔，也不需要系統管理員。
   命令列也可以：`PhoneCastShell.exe --install 名字`、`PhoneCastShell.exe --uninstall`。
4. 找不到時：點左下角頭像 → 設定 → 手動指定，3 秒內把滑鼠移到投屏視窗上。
5. 切邊不對時：設定 → 裁切，按上、下、左、右的 − ＋（按住 Shift 一次調 10），或按「自動判斷」重新判斷一次。

每個投屏軟體各記一組裁切量。第一次接上時自動判斷：
1. 名單裡有量好的就用量好的（O+互聯：上 44、下 44、左右各 4；scrcpy：不切）；
2. 否則找投屏視窗裡「手機形狀」的子視窗，很多軟體把影像放在獨立的子視窗裡；
3. 再不行就截一張圖，從四邊往內把跟邊條同色的整條（標題列、工具列）剝掉。

想留下返回／主頁鍵這類按鈕，就把對應那一邊調成 0。

## 設定檔

`%LOCALAPPDATA%\PhoneCastShell\settings.json`，改完重開程式生效。

| 欄位 | 預設 | 說明 |
|---|---|---|
| `TargetProcess` | 空白 | 名單以外也要自動找的程式名稱（不含 .exe），逗號分隔；手動指定時會自動加進來，而且優先 |
| `Profiles` | 自動產生 | 每個程式的裁切量，鍵是程式名稱小寫，例如 `"phonecast": { "Left": 4, "Top": 44, "Right": 4, "Bottom": 44 }` |
| `BossHotkey` | `Alt+Q` | 快速切換鍵，例如 `Ctrl+Shift+Z` |
| `WindowTitle` | `AI 助手` | 視窗標題 |
| `AssistantName` | `AI 助手` | 側欄、輸入框、底部提示上顯示的名字 |
| `ModelName` | `標準模型` | 輸入框右下角的模型名 |
| `UserName` | `使用者` | 左下角的使用者名稱 |
| `Logo` | `ring` | `ring`（圓環）或 `spark`（放射星） |
| `CornerRadius` | `14` | 圖片圓角 |
| `ShortcutName` | 空白 | 開始功能表捷徑的名字，空白＝還沒加；請用設定面板改，直接改這裡不會動到捷徑 |

## 原理

- O+互聯的投屏畫面不在 O+Connect 主程式裡，是另一個 Qt 程式 `app_process\phoneCast.exe`，視窗標題「手機畫面」。
- 程式在對話裡「那張圖」看得見的那一塊放一個容器，把投屏視窗改成容器的**子視窗**（`SetParent`），往左上錯開，讓標題列、按鍵列落在容器外面被擋住。
- 有系統標題列的投屏視窗（例如 scrcpy），收進來時會拿掉系統標題列並保持原本的畫面大小，畫面不會被拉伸。
- 捲動時容器跟著移動、縮小；捲出範圍或按快速切換鍵時，就把容器藏起來。
- 不用 `SetWindowRgn` 直接裁切投屏視窗：phoneCast 用 Qt 直接把影像交給 Windows 合成，裁切區域對它無效，切掉的部分會顯示成白色。
- 關掉程式時會把投屏視窗原樣還回去。

## 已知限制

- 如果程式被強制結束（例如從工作管理員關掉），投屏視窗會跟著被關掉，重新投屏就好。
- 「放大／縮小」靠改投屏視窗的大小，各家投屏軟體不一定都照比例重排畫面。

## 建置

```
dotnet publish -c Release -r win-x64 --self-contained false -o dist
```

需要 .NET 8 SDK。測試時可以用 `--process 程式名` 讓它這一次改找別的程式的視窗。
`app.ico` 是用 `PhoneCastShell.exe --write-icon app.ico` 產生的，改了 `AppIcon.cs` 的圖案要重新產生。
